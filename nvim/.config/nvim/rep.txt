   Problem:
   The autocmd closing the tree on BufEnter conflicts with `quit_on_open = true`.
   Both try to close the tree, causing:
   - Double close attempts
   - Potential window focus issues
   - Unnecessary CPU usage
   - Race conditions

   Fix:
   Delete the entire autocmd block (lines 74-84):
   ```lua

   vim.api.nvim_create_autocmd("BufEnter", {

         pcall(vim.cmd, "silent! NvimTreeClose")
       end
     end,
     nested = true,
   })
   ```

   Keep `quit_on_open = true` as the only mechanism for closing the tree.
