# server

Small shell setup for servers (Ubuntu/Debian). Just zsh, nothing else.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/zaki2993/dotfiles/main/server/install.sh | bash
```

Then log out and back in.

## What you get

- zsh as the default shell
- Prompt with `user@host`, folder, git branch and exit code
- History, completion, autosuggestions, syntax highlighting
- fzf (`Ctrl+R` history, `Ctrl+T` files)
- Aliases: `ll`, `gs`, `gp`, `gl`, `cl`, `..`, `ports`, `logs`

Your old `~/.zshrc` is saved as `~/.zshrc.bak`.
